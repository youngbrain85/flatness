# bim — 도면에서 BIM으로 (세부과업 2)

확보한 자료는 BIM 모델이 아니라 **PDF 도면**이다. 이 모듈은 그 도면에서 실 기하와
마감 구성을 복원해 DB에 싣고, IFC4로 내보낸다.

```
도면 PDF ──extract_plan──▶ 실 폴리곤 + FL/SL 레벨
                                │
                                ▼
                        PostgreSQL (013/014)
                        마감재 분류 · 로봇 임계값 · 판정
                                │
                        dump.sql │
                                 ▼
                          to_ifc ──▶ .ifc ──▶ verify_ifc
```

## 왜 선 굵기인가

LH 도면의 **면적산출근거도**는 실 경계를 굵은 선(1.42pt)으로 그리고, 가구·설비·해치는
가는 선(0.24pt)으로 그린다. 굵기로 거르면 실 경계만 남는다. 남은 선분을 축 정렬로 스냅해
폴리곤화하면 실 면적이 나오고, 그 값을 **도면에 인쇄된 면적산출표와 대조**해 검증한다.

LH 26형 결과: 7면 전부 도면 표기와 **0.0025% 이내** (정수 mm로 반올림한 뒤에도).

## 두께(THK)와 레벨(FL)은 다른 값이다

실내재료마감표의 `THK` 컬럼은 **두께**이고, 실별 마감면 레벨은 부분상세도의 `FL`/`SL`
라벨에 따로 있다. 욕실은 슬래브가 150mm 내려가 있어 두께가 가장 두꺼우면서(180) 마감면은
가장 낮다(FL+30). THK를 레벨로 읽으면 **높낮이 방향이 반대로 나온다.**

두 도면이 서로를 검증한다: `FL − SL == THK` (5개 실 전부).

## IFC로 낼 때 지키는 것

도면에 없는 값을 지어내지 않는다. 그 원칙이 IFC 구조 선택을 바꾼다.

| 상황 | 처리 |
|---|---|
| 면적 | 도면 면적표 값을 `Qto_SpaceBaseQuantities`에. 폴리곤에서 재계산하지 않는다 |
| 층별 두께가 총두께와 안 맞음 | `IfcMaterialLayerSet`(두께를 주장) 대신 `IfcMaterialConstituentSet`(주장 안 함) |
| 유효 통과폭 | `IfcDoor.OverallWidth`에 **문틀 내측 상한**만. `ClearWidthKnown=false` |
| 천장고 미기재 | 명목값으로 돌출하되 `HeightIsNominal=true` |
| 원문 모순(욕실·발코니 레벨) | 해소하지 않고 `ConflictNote`에 양쪽 보존 |
| 도면에 면이 없는 실 | 기하 없이 등재 + `EvidenceBasis='inferred'` |

## 사용

```bash
python bim/to_ifc.py        # dump.json → LH_26형_로봇친화도.ifc
python bim/verify_ifc.py    # 생성한 IFC 를 다시 읽어 검증 (실패 시 exit 1)
```

`dump.json`은 `dump.sql`을 DB에 돌려 만든다. `verify_ifc.py`는 생성 스크립트의 변수를
쓰지 않고 **파일에서만** 읽는다 — 기하를 삼각분할해 면적을 재계산하고 도면 표기와 대조한다.

## 테스트

```bash
python -m pytest bim/tests/ -q
```

도면 PDF는 `data/`가 gitignore라 저장소에 없다. 없으면 도면 의존 테스트는 skip되고
순수 기하 테스트만 돈다.

기대값은 합성 픽스처가 아니라 **도면에 인쇄된 면적표**다. 변이 실험으로 하중을 확인했다
(선 굵기·스냅 허용치·구멍링·좌표 뒤집기·축척·면 선택·FL 부호·사선 배제 10종 전부 차단,
무변이 대조군 통과).

## 한계

1. **도면 한 장으로만 검증했다.** 다른 발행 기관 도면에서는 `BOUNDARY_WIDTH_PT`를 다시 잡아야 한다.
2. **욕실 출입구 폭이 도면에 없다.** 시스템욕실 제품에 포함되어 창호 발주 대상이 아니다.
3. **유효 통과폭은 어떤 개구부도 확정되지 않는다.** 문틀 단면 상세나 시공 후 실측이 필요하다.
4. **욕실·발코니 레벨의 원문 모순이 미해소다.** 추후 확정이 필요하며, 발코니는 어느 분기를
   고르냐에 따라 발코니↔실외기실 판정이 뒤집힌다.
