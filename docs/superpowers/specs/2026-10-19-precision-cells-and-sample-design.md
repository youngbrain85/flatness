# 판정 셀 0.5/1/2m · 정밀 편차맵 화면 렌더 · 사용자 시험판 지원 설계 (스펙 2·3)

2026-10-19. 사용자 승인("진행"). 다크 테마 스펙(2026-10-17) §0의 2번·3번 갈래를 하나로 묶었다.
샘플 데이터는 사용자가 공유한 SiteScape 점군 `FF-TestBoard_Case 3.ply`(약 43cm 시험판, 6,660점, y축이 위)다.

## 1. 판정 셀 크기 (스펙 3)

- 엔진 `analyze_floor`가 판정 셀을 0.5·1·2m 세 크기로 모두 계산한다. **공식 판정은 0.5m**다
  (`stats.meta.cell_m = 0.5`, `cells.json`, `analyses.overall_verdict`, KPI, PDF 보고서가 모두 0.5m 기준).
- 1m·2m 결과는 새 산출물 `cells_alt.json`에 둔다:
  `{"by_size": {"1.0": [셀 행...], "2.0": [셀 행...]}}`. 셀 행 모양은 `cells.json`과 같다(`_cell_row`).
- 결과 화면 히트맵 스테이지 위에 0.5 / 1 / 2m 전환을 둔다. 전환하면 히트맵·HUD(칸 수·최댓값)만 바뀐다.
  KPI·등급 분포·결과표·보고서는 공식(0.5m) 그대로이고, 히트맵 쪽에 "판정은 0.5m 기준" 안내를 단다.
  `cells_alt.json`이 없는 분석(옛 분석·벽면)은 전환을 숨긴다.
- 벽면 분석은 이번 범위 밖이다(지금 값 그대로).

## 2. 정밀 편차맵 화면 렌더 (스펙 2)

- 엔진이 판정에 쓴 5cm 서브셀 잔차를 `residual_grid.json`으로 내보낸다:
  `{"subcell_m": 0.05, "cols": n, "rows": m, "values": [행 우선, 0.1mm 단위 정수, 값 없음은 null]}`.
  행 0 이 y 가장 작은 쪽이다(엔진 격자 그대로).
- 화면은 편차맵 탭에서 이 격자를 캔버스로 그린다. 표시 해상도 5 / 10 / 20cm 전환, 기본 5cm.
  10·20cm는 그 안 5cm 값들의 평균(값 있는 것만)이다.
- 색: 꺼짐(−)=파랑, 0=어두운 남색, 솟음(+)=주황→빨강. 초록은 쓰지 않는다(3D 뷰어 "평탄=초록"과 뜻이
  겹치지 않게). 색 범위는 대칭 ±R, R = |값|의 98번째 백분위(최소 1mm). 범례에 −R·0·+R(mm)을 적는다.
  값 없는 칸은 칠하지 않는다(검정 스테이지가 보인다).
- `residual_grid.json`이 없는 분석은 지금처럼 엔진 PNG(`deviation_paths`)를 보여 준다.
- PDF 보고서의 편차맵은 지금 밝은 PNG 그대로다.

## 3. 높이 그림 (단위 확인·정합 화면)

- 엔진 `render_height_view`가 바탕을 투명하게 그린다(값 없는 칸도 투명). 검정 스테이지 위에서 보인다.
  정합 클릭용 `height_view_plain.png`과 좌표 사이드카는 바꾸지 않는다.

## 4. 사용자 시험판 지원

- **축 방향:** PLY 헤더 주석에 `SiteScape`가 있으면 y축이 위인 좌표계로 보고 `(x, y, z) → (x, −z, y)`로
  돌려 읽는다(엔진 리더 한 곳, 모든 단계가 같은 리더를 쓴다). 다른 파일은 지금처럼 z가 위다.
- **작은 시편:** 1㎡ 이상 구역이 하나도 없을 때, 가장 큰 연결 덩어리가 유효 서브셀의 80% 이상이면 그 덩어리를
  판정 구역으로 인정하고 경고 `small_specimen`을 단다. 보통 스캔의 가구·파편 배제는 그대로다.
- **3D 뷰어 점 크기:** 점 수가 상한보다 훨씬 적어 표본 칸이 실제 점 간격보다 작으면, 표본 칸 변을 실제 점 간격
  (√(바닥 면적 / 점 수))으로 키워 적는다. 뷰어는 이 값으로 점 크기를 잡으므로 성기게 보이지 않는다.
- 43cm 판은 0.5m 셀로도 판정 칸이 1~2개다. 이 샘플의 주 볼거리는 5cm 편차맵과 3D다.

## 5. 운영 데이터

- 기존 분석·보고서를 soft delete 한다(`deleted_at`, 복구 가능). 저장소 객체는 지우지 않는다.
- 새 현장 "샘플 시험판" > 측정위치 "시험판 Case 3"에 시험판을 올려(단위 m) 새 엔진으로 분석한다.

## 6. 바뀌지 않는 것

DB 스키마·RLS, 구배(2m, 과업지시서 단위), 벽면 판정, PDF 보고서 양식, 3D 뷰어 로직(점 크기 입력값만 바뀜),
"브라우저는 등급을 계산하지 않는다"(셀 등급은 엔진이 cells·cells_alt에 적은 값을 칠할 뿐).

## 7. 검증

엔진 pytest(축 회전, 작은 시편, 세 셀 크기, 잔차 격자, 투명 높이 그림, 점 크기), 워커 pytest, 대시보드 vitest
(셀 전환, 편차맵 캔버스·해상도 평균·색 범위, 옛 분석 대체 표시). 시험판을 로컬 엔진으로 분석해 산출물을 확인하고,
배포 뒤 운영에 올려 분석이 끝나는지 확인한다.
