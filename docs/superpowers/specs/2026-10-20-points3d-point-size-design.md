# 3D 프리뷰 점 크기 메뉴 설계

2026-10-20. 사용자 승인("이대로 진행"). 참고: CloudCompare 는 3D 뷰 왼쪽 위에 "Default point size − +"를 두고
보이는 모든 점의 크기를 한 번에 키우거나 줄인다(고정 화면 px 1~16).

## 결정

- 3D 프리뷰 맵(뷰어 스테이지) **왼쪽 위**에 `점 크기  −  ×1  +` 를 둔다.
- 기본은 지금 크기(×1). −/+ 로 **×0.25 · ×0.5 · ×0.75 · ×1 · ×1.5 · ×2 · ×3 · ×4** 사이를 한 단계씩 움직인다.
  끝 단계에서는 그쪽 버튼이 꺼진다(disabled).
- 크기 방식은 지금 그대로다: 점의 실제 크기(m) = 0.55 x `sample_cell_m` 에 배율을 곱하고, 화면 크기는 거리에 따라
  바뀐다. 최소 크기(1.5 CSS px)도 같은 배율을 곱한다(그래야 작게 할 때 최소 크기에 막히지 않고 실제로 작아진다).
  최소는 드로잉 버퍼 1px 아래로 내려가지 않고, 최대는 장치 한계(ALIASED_POINT_SIZE_RANGE) 그대로다.
- 배율은 과장·임계값·배경처럼 뷰어 안 상태다. 다른 분석으로 바꾸면(뷰어 새로 마운트) ×1 로 돌아간다. 판정·보고서와 무관.
- 버튼은 다른 도구 버튼과 같은 44px 이상, 바탕은 HUD 와 같은 뷰어 배경색 반투명(축 라벨과 겹쳐도 읽히게).

## 바뀌지 않는 것

점 표본·색·범례·HUD·조작·읽기 창, 엔진·워커, 다른 탭.

## 검증

vitest: 배율 단계·끝 단계 disabled·렌더러에 넘기는 점 크기(m)와 최소 px 가 배율만큼 바뀜, 분석 전환 시 ×1.
로컬 화면 캡처(1440·390)로 왼쪽 위 배치와 점 크기 변화 확인.
