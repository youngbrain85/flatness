# 기준면 잡음 σ·결함 빼기 출발점 (2026-10-20, 엔진 p4-0.7.2)

> 바닥 기준면 개선 스펙(`2026-10-20-floor-reference-surfaces-design.md`) §2 의 국부·전체 기준면 계산을 고친다.
> 사용자 보고: "RANSAC 평면 찾는 거 다시 검토해 봐. 기준평면이 제대로 안 나와. iteration 을 늘리거나 파라미터를 고쳐야".

## 원인 (운영 시험판 FF-TestBoard Case 3 실측)

- 구역 평면(RANSAC 500회, 문턱 5mm)은 맞았다: 테두리 0mm 근처, 가운데 오목부 −15~−21mm. 반복 횟수 문제가 아니다.
- 국부·전체 기준면의 결함 문턱 3σ 의 σ 를 "1회차 창 평면 잔차의 MAD" 로 쟀다. 오목부가 면적 42% 라 결함 자체가
  잡음으로 재어져 σ = 9.1mm, 문턱 27mm. 2회차 결함 빼기도 전체 MSAC 도 아무것도 거르지 못해 두 기준면 모두 결함을
  섞은 평균 평면(테두리 +5~+10, 오목부 −7~−14)이 되었다. 화면의 편차맵·3D 점 색·반투명 기준면이 모두 이 평면 기준이었다.

## 바꾼 것 (`engine/flatness/core/reference.py`)

1. **σ = 칸 높이 잡음**: 이웃 칸 2차 차분(z[i-1] − 2z[i] + z[i+1])의 MAD x 1.4826 / √6 (`cell_noise_sigma`, 세 칸 모두
   유효할 때만 센다). 기울기는 0, 완만한 휨은 거의 0, 넓은 결함은 벽 칸에만 걸린다. 시험판 9.1 → 2.0mm. 국부 문턱
   max(3mm, 3σ)·전체 MSAC 문턱 max(5mm, 3σ) 식은 그대로다. 대개 σ 가 작아 문턱은 하한(3mm/5mm)이 된다. 높이가 양자화되어
   2차 차분이 거의 0 이면 σ 도 0 이 되어 하한을 쓴다(리뷰 실측: 공간 상관 잡음에서는 실제보다 작게 잰다, 하한이 막는다).
2. **결함 빼기의 출발점**: 칸마다 후보 둘(거르지 않은 창 평균 평면, 구역 RANSAC 평면) 중 그 칸 창 안에서 문턱 이내로 맞는
   칸이 더 많은 것(`_best_start`, RANSAC 의 합의 크기 비교). 창 평균만 쓰면 넓은 오목부가 평균을 끌어내려 벽 칸만 남았고
   (3x3m 바닥의 1.0x1.0m 오목부 바닥 −18.1mm, 참값 −20mm), 구역 평면만 쓰면 처짐·10% 램프 끝이 통째로 빠져 구역 평면으로
   떨어졌다(최대 47mm). 리뷰 중간안(25cm 블록 중앙값 출발)은 작은 판에서 블록 2x2 의 가운데 둘 평균이 되어 테두리와
   오목부 사이에 놓였고(테두리 4.78mm), 후보로 더해도 나아지지 않아 뺐다.
3. 출발점에서 결함 칸을 빼고 맞추기를 2회 한다(1회면 1.2m 판 테두리가 덜 붙는다).

## 결과

- 운영 시험판: 국부·전체 기준면이 테두리에 붙는다(구역 평면 대비 차이 0.8mm 이내, 오목부 −19~−21mm).
- 43cm 판 아래쪽 오목부(벽 6cm): 테두리 최대 0.38mm·바닥 −19.7mm(고치기 전 5.66mm·−16.3mm).
- 옛 구현과 견줌: 램프 끝 7% 13.0 → 14.0mm, 10% 18.0 → 18.7mm, 처짐 30mm/4m 같음(−2.05 ~ +0.98mm),
  물결 10mm/2.4m ±3.1 → ±3.6mm(문턱이 하한 3mm 라 물결 마루·골 일부가 결함으로 빠진다), 합성 방 등급 같음.
- 처리 시간(국부 기준면만): 30x40m 0.57 → 0.95초, 100x100m 6.1 → 9.3초.
- 한계: 창(1m) 안에서 결함이 절반을 넘으면 두 후보 모두 결함 쪽이 될 수 있다(1m 보다 넓은 결함은 전체 기준에서 본다,
  바닥 기준면 스펙 §8).
- 판정(직선자, 구역 평면 잔차)은 바뀌지 않는다.
