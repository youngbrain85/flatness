# 기준면 잡음 σ·결함 빼기 출발점 (2026-10-20, 엔진 p4-0.7.2)

> 바닥 기준면 개선 스펙(`2026-10-20-floor-reference-surfaces-design.md`) §2 의 국부·전체 기준면 계산을 고친다.
> 사용자 보고: "RANSAC 평면 찾는 거 다시 검토해 봐. 기준평면이 제대로 안 나와. iteration 을 늘리거나 파라미터를 고쳐야".

## 원인 (운영 시험판 FF-TestBoard Case 3 실측)

- 구역 평면(RANSAC 500회, 문턱 5mm)은 맞았다: 테두리 0mm 근처, 가운데 오목부 −15~−21mm. 반복 횟수 문제가 아니다.
- 국부·전체 기준면의 결함 문턱 3σ 의 σ 를 "1회차 창 평면 잔차의 MAD" 로 쟀다. 오목부가 면적 42% 라 결함 자체가
  잡음으로 재어져 σ = 9.1mm, 문턱 27mm. 2회차 결함 빼기도 전체 MSAC 도 아무것도 거르지 못해 두 기준면 모두 결함을
  섞은 평균 평면(테두리 +5~+10, 오목부 −7~−14)이 되었다. 화면의 편차맵·3D 점 색·반투명 기준면이 모두 이 평면 기준이었다.

## 바꾼 것 (`engine/flatness/core/reference.py`)

1. **σ = 칸 높이 잡음**: 이웃 칸 2차 차분(z[i-1] − 2z[i] + z[i+1])의 MAD x 1.4826 / √6 (`cell_noise_sigma`).
   기울기는 0, 완만한 휨은 거의 0, 넓은 결함은 벽 칸에만 걸린다. 시험판 9.1 → 2.0mm. 국부 문턱 max(3mm, 3σ)·전체 MSAC 문턱
   max(5mm, 3σ) 식은 그대로다.
2. **결함 빼기의 출발점**: 창 평균 평면 대신 구역 평면 잔차의 25cm 블록 중앙값을 창(1m) 크기로 다시 중앙값 낸 면
   (`_robust_start`). 창 평균 평면은 창 가장자리에 걸친 넓은 오목부에서 벽 칸만 남겨 기준면이 끌려 내려갔다
   (3x3m 바닥의 1.0x1.0m 오목부: 바닥 −18.1mm, 블록 중앙값 출발 −19.0mm, 참값 −20mm).
3. 출발점에서 결함 칸을 빼고 맞추기를 2회 한다(1회면 1.2m 판 테두리 오차 1.10mm, 2회 0.82mm).

## 결과

- 시험판: 국부·전체 기준면이 테두리에 붙는다(테두리 중앙값 −0.4mm, 오목부 −21.1mm, 구역 평면과 차이 0.8mm 이내).
- 합성 방(처짐·범프·함몰·욕실): 국부 −5.8 ~ +8.4mm(이전 −5.7 ~ +8.3), 등급 분포 같음. 결함이 좁은 바닥은 그대로다.
- 한계: 창(1m) 안에서 결함이 절반을 넘으면 출발점이 결함 쪽에 놓인다(1m 보다 넓은 결함은 전체 기준에서 본다, 바닥 기준면 스펙 §8).
- 판정(직선자, 구역 평면 잔차)은 바뀌지 않는다. 처리 시간: 30x40m 바닥 0.6 → 1.1초.
