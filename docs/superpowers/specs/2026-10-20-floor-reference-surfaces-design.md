# 바닥 기준면 개선(구역 나누기 교체 · 국부/전체 기준면 · 3D 표시) 설계

2026-10-20. 사용자 승인("B 로 하되 기준면들을 같이 시각화해서 3D 프리뷰에서 볼 수 있게", 설계안 "이대로 진행").

## 0. 왜 바꾸나 (실측)

| 상황 | 지금 결과 |
|---|---|
| 16m 바닥, 경사 2.5%·3% (한 장의 평면) | 구역 0개 → 분석 실패 |
| 8m 바닥, 경사 3% | 평면 하나가 구역 3개로 쪼개짐 |
| 8x8m, 가운데 10mm 처짐, 국부 결함 없음 | 편차맵 −6.8 ~ +4.6mm(그릇 모양), 직선자 틈새 최대 3.1mm |

원인: 바닥 레벨을 높이 히스토그램 봉우리로 찾는다(경사면은 봉우리가 없다). 기준면이 구역마다 평면 하나라 처짐·드리프트
같은 긴 휨이 편차로 남는다(직선자 판정에는 거의 안 잡혀 화면과 판정이 엇갈린다). 구역 사이 높이 차이는 보이지 않는다.

## 1. 구역 나누기 교체 (엔진 `core/zones.py`)

- 이웃한(4방향) 5cm 서브셀의 중간값 높이 차이가 **1.5cm 이하**이면 같은 면으로 잇는다(연결 요소). 경사·완만한 휨은 한 면,
  단차·가구 상판처럼 높이가 끊기는 곳에서 나뉜다. 높이 히스토그램 레벨 검출(`core/levels.py`)은 더 이상 쓰지 않아 지운다.
- 그대로 두는 것: 최소 면적 1㎡(작은 시편 예외 포함), 가구 상판 규칙(주 구역 높이 +0.3m 초과·3㎡ 이하), 유령층 규칙(쌍봉 20% 초과),
  쌍봉 서브셀 잔차 NaN, 구역별 RANSAC 평면(`zones[].plane_abc`)과 그 잔차.
- 구역의 `level_m` 은 그 구역 서브셀 높이의 중간값이다. 평면 추종 성장 단계는 연결 요소가 경사를 이미 품으므로 없앤다.
- **판정은 구역 평면 잔차로 지금과 같은 직선자 계산**이다(직선자 틈새는 직선 성분과 무관해 기준면 선택과 무관). 다만 구역이
  바뀌므로 예전에 쪼개지거나 실패하던 경사 바닥은 이제 한 구역으로 판정된다.

## 2. 기준면 두 개 (엔진 새 모듈 `core/reference.py`)

- **잡음 크기 σ:** 국부 기준 1회차 잔차의 MAD x 1.4826 (값 있는 바닥 서브셀 전체).
- **국부 기준면(기본):** 각 바닥 서브셀마다 같은 구역의 서브셀만으로 중심 3m x 3m(한 변 61칸) 창에 최소제곱 평면을 맞춰 그 칸
  중심 높이를 기준으로 삼는다. 2회: 1회차 잔차가 `max(3mm, 3σ)` 를 넘는 칸(결함)을 빼고 다시 맞춘다. 누적합 표(summed-area
  table)로 창 합을 O(1)에 구한다. 창 안 유효 칸이 30개 미만이거나 평면이 퇴화하면(일직선 등) 그 칸은 구역 평면 값을 쓴다.
- **전체 기준면:** 가구·유령층을 뺀 바닥(ok 구역) 전체 서브셀에 RANSAC 평면 하나. 문턱 `max(5mm, 3σ)`, 뒤이어 인라이어 최소제곱.
  전체 기울기·방 사이 높이 차·의도된 단차가 보인다. 중력 기준 진짜 수평은 이번 범위 밖이다.
- 편차: `local = median_z − 국부 기준`, `global = median_z − 전체 기준`(쌍봉·구역 밖은 NaN).

## 3. 산출물 (stats-schema 계약 갱신)

- `residual_grid.json` schema_version 2: `values`(국부 기준, 0.1mm 정수|null) + `values_global`(전체 기준). 행 우선, 행 0 = y 최소.
  키 `values_global` 이 없으면 옛 형식(구역 평면 기준)이다.
- `reference_surfaces.json`(새, stats `reference_surfaces_path`): 25cm 격자(5cm 서브셀 5x5 묶음의 가운데 칸 값) 위의 두 기준면 높이.
  `{"step_m": 0.25, "cols", "rows", "local": [...], "global": [...]}`. 높이는 0.1mm 정수, 좌표틀은 points3d 와 같은 파일-로컬
  (x·y 원점 = 서브셀 격자 원점 = bbox 최소, z 원점 = bbox 최소 z). 바닥이 아닌 마디는 null.
- 정밀 편차맵 PNG(`deviation.png`, PDF 용)·3D 프리뷰 PNG·`points3d.bin` 편차는 **국부 기준**으로 바뀐다(형식 그대로).
- 판정 산출물(cells·stats 수치·cells_alt)은 형식·계산 그대로.

## 4. 화면

- **정밀 편차맵 탭:** 스테이지 도구 줄에 `기준면 [국부] [전체]`(기본 국부). 색 범위 R 은 고른 기준의 값으로 계산.
  설명 문구에 "3m 국부 기준면 대비 / 바닥 전체 평면 대비"를 밝힌다. 옛 분석(values_global 없음)은 전환을 숨기고 "구역 평면 기준".
- **3D 프리뷰:**
  - 도구 줄 `기준면 [국부] [전체]`: 점 색과 과장의 기준. 전체로 바꾸면 점 편차를 `국부 편차 + (국부 기준 − 전체 기준)` 으로
    브라우저가 다시 계산한다(두 기준면 25cm 격자를 쌍선형 보간).
  - `국부 기준면 보기` · `전체 기준면 보기` 버튼(누름 상태): 기준면을 반투명 면으로 겹쳐 그린다. 국부 = 흰색, 전체 = 파랑
    (초록은 3D "평탄"과 겹쳐 쓰지 않는다). 고른 기준면 R 은 제 높이에, 다른 기준면 S 는 `R + 과장 x (S − R)` 높이에 그려
    과장 배율에서도 점·두 면의 관계가 맞는다. 보이는 기준면은 범례에 한 줄씩 더한다.
  - `reference_surfaces.json` 이 없거나 못 받으면 기준면 줄을 숨기고 지금처럼 그린다(옛 분석).
- 점 크기 메뉴·HUD·읽기 창은 그대로(읽기 창 편차는 고른 기준의 값).

## 5. 바뀌지 않는 것

판정 방식·등급 계산·KPI·결과표·cells·cells_alt, 구배 분석, 벽면 분석, DB 스키마, PDF 양식(편차맵 그림과 캡션 문구만 국부 기준으로).

## 6. 검증

엔진 pytest: 경사 2.5%·3% 16m 한 구역, 15cm 단차 두 구역, 1cm 턱은 한 구역, 기존 구역 테스트(두 방·가구·유령층·최소 면적·경사),
10mm 처짐의 국부 편차 ±2mm 이내·함몰 10mm 보존, 전체 기준이 단차를 드러냄, 산출물 모양·좌표틀.
대시보드 vitest: 편차맵 전환·옛 형식, 3D 기준 전환(점 편차 재계산·uniform), 기준면 표시 버튼·범례, 옛 분석 숨김.
